# Known issues / 알려진 문제

0.4.11 Beta

| Area | English | 한국어 |
| --- | --- | --- |
| Dragging | Occasional long frame gaps remain, especially with large rugs or busy systems. | 큰 양탄자나 PC 부하에 따라 순간적인 끊김이 남아 있습니다. |
| Folds and fringe | Complex folds can show overlap or bunching, especially with long fringe. | 복잡한 접힘과 긴 테슬에서 겹침·뭉침이 나타날 수 있습니다. |
| Restored folds | Saved coordinates are restored; the drawing order of some complex folds can look different. | 좌표는 복원되어도 일부 복잡한 접힘의 표시 순서가 달라 보일 수 있습니다. |
| Displays | Extended use, different scaling levels and multi-monitor layouts need more testing. | 장시간 사용·다양한 화면 배율·다중 모니터는 추가 확인이 필요합니다. |
| Signing | The beta installer is unsigned. Windows may show a warning. | 설치 파일에 디지털 서명이 없어 Windows 경고가 나타날 수 있습니다. |
| Language | Switching takes effect after quitting and reopening. Windows dialogs may use the OS language. | 언어 변경은 앱 재실행 후 적용됩니다. Windows 기본 창은 OS 언어를 따를 수 있습니다. |

If you lose sight of the rug, try **Ctrl + Alt + Backspace** to center and unfold it. This resets its folded shape. If a shortcut is used by another app, use the rug's system tray menu. Hide the rug temporarily with **Ctrl + Alt + Shift + R**.

양탄자가 보이지 않으면 **Ctrl + Alt + Backspace**로 가운데에 가져와 펼칠 수 있습니다. 이때 접힌 모양은 초기화됩니다. 단축키가 다른 앱과 겹치면 트레이 메뉴를 이용하세요. **Ctrl + Alt + Shift + R**로 잠시 숨길 수 있습니다.

There is no automatic update downloader. Download a newer installer when you choose to update. Back up important designs before updating.

자동으로 새 버전을 내려받지 않습니다. 업데이트하려면 새 설치 파일을 직접 받으세요. 중요한 디자인은 먼저 백업해 주세요.
