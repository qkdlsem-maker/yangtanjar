# Privacy / 개인정보 안내

Yangtanjar 0.4.11 Beta · 2026-10-29

## English

Yangtanjar does not include account registration, ads, analytics, network uploads or automatic update downloads. It reads desktop icon positions and sizes to shape the rug. It does not read icon file names or contents, or move or delete desktop files.

An image you choose to import is read and copied into your local design library, along with working images and thumbnails. Editable patterns, strokes, drafts, settings and folded shapes are saved locally. PNG exports and design backups are written to locations you choose. Restoring a backup creates a safety copy first.

Data folders are listed in the [installation guide](INSTALL.en.md). Uninstalling keeps personal data. Error logs can contain file paths and diagnostic details; the app does not upload them.

Support is provided through [qkdlsem-maker's project issues](https://github.com/qkdlsem-maker/yangtanjar/issues). GitHub issues and attachments are public and handled by GitHub. Do not post passwords, private desktop screenshots, full settings folders or `.yrbackup` files. The app does not send reports automatically.

## 한국어

양탄자야르는 회원 가입·광고·분석 서비스·네트워크 업로드·자동 업데이트 다운로드 기능을 포함하지 않습니다. 양탄자 모양을 계산하기 위해 바탕화면 아이콘의 위치와 크기를 읽습니다. 아이콘 파일 이름·내용을 읽거나 파일을 이동·삭제하지 않습니다.

사용자가 선택한 이미지를 읽고 원본 사본·작업용 이미지·미리보기를 PC의 디자인 라이브러리에 저장합니다. 문양·그린 선·초안·설정·접힌 모양도 로컬에 저장합니다. PNG 내보내기와 디자인 백업은 사용자가 고른 위치에 저장합니다. 백업 복원 전에는 안전 사본을 만듭니다.

저장 경로는 [설치 안내](INSTALL.ko.md)에 있습니다. 앱을 제거해도 개인 데이터는 보존됩니다. 오류 기록에는 파일 경로 등 진단 정보가 포함될 수 있으며, 앱이 이를 업로드하지 않습니다.

지원 창구는 [qkdlsem-maker의 프로젝트 Issues](https://github.com/qkdlsem-maker/yangtanjar/issues)입니다. GitHub 게시물과 첨부 파일은 공개되며 GitHub에서 처리합니다. 비밀번호·개인 바탕화면 캡처·설정 폴더 전체·`.yrbackup` 파일을 올리지 마세요. 앱이 제보를 자동 전송하지 않습니다.
