# 양탄자야르 설치와 사용

[English](INSTALL.en.md) · [처음으로](../README.ko.md)

## 설치

1. [v0.4.11-beta.1 릴리스](https://github.com/qkdlsem-maker/yangtanjar/releases/tag/v0.4.11-beta.1)를 엽니다.
2. Assets에서 **Yangtanjar-0.4.11-Setup-x64.exe**를 받습니다. GitHub가 자동으로 표시하는 **Source code** 압축 파일에는 저장소 문서가 들어 있으며, 실행용 앱이 아닙니다.
3. 설치 파일을 실행하고 설치 화면 언어를 고릅니다.
4. 시작 메뉴에서 양탄자야르 / Yangtanjar를 실행합니다.

Windows 10 버전 2004 이상 / Windows 11 x64, .NET Framework 4.8 이상이 필요합니다. 현재 사용자 계정에 설치하며 관리자 권한을 요구하지 않습니다. ARM64와 32비트 Windows는 이번 베타의 검증 대상이 아닙니다.

설치 파일에 디지털 서명이 없어 Windows에서 게시자 또는 평판 확인 경고가 나타날 수 있습니다. 설치를 위해 Windows 보호 기능을 끄지 마세요. 파일이 확실하지 않으면 취소하세요. 함께 제공하는 `SHA256SUMS.txt`로 배포본과 같은 파일인지 비교할 수 있지만, 해시 일치가 보안 인증을 뜻하지는 않습니다.

## 언어

첫 실행은 한국어 Windows에서 한국어, 그 외에는 영어입니다. 설정 창 오른쪽 위에서 **한국어**, **English**, **자동 / System**을 선택한 다음 **앱 종료**를 누르고 다시 실행하세요. 언어 선택은 저장됩니다. 양탄자의 접힌 모양이나 저장된 디자인 이름은 바꾸지 않습니다. Windows 파일 선택창과 기본 대화상자 버튼은 Windows 언어를 따를 수 있습니다.

## 설정 열기와 종료

양탄자를 우클릭해 **디자인과 설정**을 누르거나, 작업 표시줄의 숨겨진 아이콘 영역에서 양탄자 아이콘을 두 번 클릭합니다. 설정 창을 닫아도 양탄자는 유지됩니다. 완전히 끄려면 **앱 종료** 또는 트레이 메뉴의 **종료**를 사용하세요.

**Alt**를 누르면 아래 아이콘을 조작할 수 있습니다. **Shift + 드래그**는 전체 이동, **Ctrl + 마우스 휠**은 크기 조절, 마우스 휠은 회전입니다. **Ctrl + Alt + Shift + R**은 숨김·표시, **Ctrl + Alt + Backspace**는 가운데로 가져와 펼치기입니다.

## 디자인 만들기와 보관

**이미지 추가**는 PNG·JPEG·BMP를 지원합니다. 이미지 자체에 그려진 테슬과 배경은 잘라 주세요. 앱이 별도로 테슬을 붙여 표시·길이·색상을 조절합니다. 이미지 제한은 100MB, 8천만 화소 이하, 가로세로 비율 1:3~3:1입니다.

**직접 디자인**에서 문양·색상·테두리와 자유 그리기를 함께 사용할 수 있습니다. **저장하고 양탄자로 적용**하면 내 디자인에 추가됩니다. **PNG로 내보내기**는 별도 테슬을 제외한 양탄자 몸통을 저장합니다.

**보관과 복원**을 펼치면 디자인 백업, `.yrbackup` 복원, 초안 이어서 편집을 사용할 수 있습니다. 백업에는 추가한 이미지 원본·그림·설정이 포함될 수 있으므로 개인적으로 보관하세요. 마지막 자동 저장 이후의 최근 작업은 비정상 종료 시 남지 않을 수 있습니다.

## 업데이트와 제거

디자인을 백업한 뒤 새 설치 파일을 실행하세요. 실행 중인 앱에 작업 저장·보관과 안전한 종료를 요청합니다. 취소하거나 안전하게 닫지 못하면 설치를 중단합니다. 아주 오래된 버전은 직접 닫아야 할 수 있습니다. 여러 양탄자 버전을 동시에 실행하지 마세요.

**Windows 설정 → 앱 → 설치된 앱** 또는 **앱 및 기능**에서 제거할 수 있습니다. 제거 후에도 개인 디자인·설정·초안은 남습니다. 자동 시작을 등록하거나 배경화면을 변경하거나 바탕화면 파일을 이동하지 않습니다.
