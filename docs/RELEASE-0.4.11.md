# Yangtanjar 0.4.11 Beta · 한국어 / English

## English

A free Windows beta of Yangtanjar: a desktop rug you can fold, move and make your own.

**New in 0.4.11:** English and Korean app menus, the design editor, backup/recovery screens and messages. Choose a language in the top-right selector, quit the app, and reopen it. Windows system dialogs may keep the Windows language.

The 0.4.10 frame scheduling improvement is retained. Motion calculations and grab behavior are unchanged, including Calm's 0.4.6 behavior. Existing design names and pattern data are preserved. This is not a new fix for fold or fringe overlap.

Includes 16 rug designs, image import, patterns and freehand drawing, adjustable fringe, saved desktop folds, draft recovery, and design backups.

**Download:** `Yangtanjar-0.4.11-Setup-x64.exe`. The same installer supports both languages. Read `START-HERE.en.txt` or `START-HERE.ko.txt`; `SHA256SUMS.txt` identifies the attached files. GitHub's automatic Source code archives contain documentation, not the app.

**Known limitations:** occasional stutter, overlap around complex folds and long fringe, and some differences in draw order after restoring a complex fold. Wider hardware and multi-monitor testing is still needed. The installer is unsigned. This is a pre-release, not a Microsoft Store-certified release.

Please report your app version, Windows version, what you did, and what happened. A short clip or screenshot is welcome after removing private information. Use the repository's English or Korean issue form.

## 한국어

16종 디자인, 이미지 추가, 문양 편집과 자유 그리기, 테슬 조절, 접힌 모양 저장, 초안 복구, 디자인 백업을 제공합니다.

**남은 문제:** 간헐적인 버벅임, 복잡한 접힘·긴 테슬의 겹침, 일부 접힘 복원 시 표시 순서 차이. 다양한 PC·다중 모니터는 추가 확인이 필요합니다. 설치 파일은 미서명이며 Microsoft Store 심사를 마친 제품이 아닙니다.
